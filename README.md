# CRUD Barang - Laravel

## Deskripsi
Aplikasi CRUD Barang ini dibuat menggunakan Laravel untuk mengelola data barang (tambah, lihat, edit, hapus).  
Project ini dibuat sebagai latihan dasar Laravel.



## Fitur
- Tambah data barang
- Menampilkan data barang
- Edit data barang
- Hapus data barang



## Teknologi
- PHP
- Laravel
- CSS
- MySQL



## Cara Menjalankan Project

1. Buka Terminal

2. Masuk ke folder project:
   cd crud-barang

3. Jalankan server Laravel:
   php artisan serve

http://127.0.0.1:8000/barang
